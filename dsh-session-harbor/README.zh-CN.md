# Session Harbor

[English](README.md) · 简体中文

本机与 SSH 远端会话放在同一工作台的「已置顶」「活跃」「工作中」「已完成」四组中。点击远端行，在当前主区域打开该设备的原生会话界面。本机侧栏和外壳保留。新会话先选择设备，再选择该设备的项目。

## 使用

- 打开「设置 → Session Harbor SSH」，从本机 SSH 配置选择主机或输入 `user@host`。这里可以重连、断开和移除已保存的设备。SSH 认证使用本机 OpenSSH 配置和 SSH agent，远端需要安装 DSH。
- 在同一份会话列表中直接切换本机和远端会话。分组折叠、整行打开和键盘操作适用于两种会话。时间显示在会话标题右侧，远端会话的主机名显示在右上。
- 设备选择本身不创建会话。选定项目后，在所属设备创建或复用空会话，并打开返回的 ID。
- 「添加工作区」在本机和 SSH 设备上共用双栏目录弹窗。可以使用面包屑或直接输入路径，查看隐藏文件夹，并在所选设备上新建文件夹。
- 原生正文、输入、模型、附件、审批与用户问答由该设备独立的官方 DSH Client 运行时装配。界面语言跟随本机工作台，会话操作发送到所属设备。
- 置顶使用所属设备的 DSH 状态，完成使用该设备插件的持久状态。等待审批或问答的普通会话列在「活跃」组顶部，该组标题会显示待操作数量。普通运行结束保留两秒缓冲，再回到「活跃」组。「已置顶」和「已完成」优先于「工作中」。
- 会话菜单提供打开、置顶、完成、重命名、分叉、复制 ID 与归档。离线写操作禁用。项目管理在独立入口中进行，会话右键菜单不提供删除项目操作。
- 「已置顶」和「活跃」在列表上方，「工作中」和「已完成」固定在底部。「已置顶」无会话可显示时隐藏。各组可以折叠，行数较多时在组内滚动。「工作中」从空组变为有会话时自动展开，「已完成」默认收起。深浅主题使用宿主主题变量，减弱动态效果时停止状态图标旋转。底部按钮可切回原生侧栏。

## 版本与依赖

旧版「T3 会话侧边栏」使用另一包名。升级时先从 DSH 插件管理器卸载旧版，再安装 Session Harbor。原有会话、置顶、已完成状态和 SSH 主机设置可继续使用。

本版本为 `0.2.8`，支持 DSH `0.2.2-rc.3` 和 `0.2.2-rc.5`。工作台会为已就绪的 SSH 连接在后台初始化远端客户端，切换会话时复用该客户端。侧栏使用宿主导航下方的可用高度，空间不足时切换为整份列表滚动。活动远端会话接收其自己的快捷键，左栏继续由本机窗口控制。

插件启动后会自动尝试连接在「设置 → Session Harbor SSH」里保存的设备。侧栏保留这些设备的最近一次同步数据，移除设备时清除相应的本地缓存。远端会话的完成状态与实时分组同步需要远端也安装本侧栏插件。远端原生会话需要与本机匹配的 DSH 版本。

远端首次安装时，既有非空、未归档、未运行的普通会话会执行一次完成状态迁移，已有迁移记录会保留。置顶与完成横跨两个存储服务，失败后重新读取实际状态。对于远端已创建而回包丢失的跨连接重试，无法保证分布式 exactly-once。

## 构建与验证

在仓库根目录运行以下命令。

```sh
npm --prefix dsh-session-harbor ci
node tools/build-client.mjs
node tools/build-client.mjs --check
node --test dsh-session-harbor/*.test.js
```

构建生成包内的 `client.remote-runtime.js`。测试覆盖连接世代、协议、认证资源路由、存储隔离、状态合并、创建幂等、导航生命周期及快捷键所有权。旧 jsdom 行结构脚本已停用。它曾把远端点击无效果当成成功，无法验证当前原生运行时。

已在现有 Desktop `0.2.2-rc.5` 工作台通过只读探针加载 `wsl` 和 `2060` 各一条已有会话，确认两台设备的原生对话与可编辑输入框均挂载。发送目标使用官方客户端和隔离传输验证。真实远端消息、审批、附件以及右栏的视觉效果仍需对应操作验收。

更新本机已加载的 Host 模块时，按插件管理器的应用结果重启 DSH。通过当前页面的 Client Inspect 可以确认已连接工作台上的入口注册。

完整设计与验收范围见[远端会话设计](../docs/remote-aggregation-design.md)。
